# RAG 的最小实现

RAG（Retrieval-Augmented Generation，检索增强生成）的核心不是“接一个向量库”，而是三件事：

1. 切块：把长文按段落和句边界切成块，块之间保留少量重叠，避免答案被切断；
2. 检索：把问题与块都转成可比较的表示，召回最相关的 top-k；
3. 引用：把命中的原文按编号放进上下文，要求模型只依据资料回答，并标注 [1][2] 来源。

## 常见问题

- 只做关键词匹配会漏掉同义表达；只做向量召回可能召回语义相近但事实不对的块；
- 切块太大，检索不准；切块太小，答案被切断；
- 没有引用的 RAG 无法核对，模型仍可能编造；
- 平均分不等于真实效果，必须看失败样本。

## 本项目的取舍

hello_agents 的 RAG 用纯 Python BM25（中文按字符 bigram 切）做检索，不引入向量库；返回 answer 与 sources，答案中的编号能对回原文。没有模型 Key 时退化为返回检索到的原文，不编答案。
